## 📌 Community Rules

To keep this community useful and welcoming:

* Be respectful and professional.
* Help others learn and grow.
* Keep discussions constructive.
* Follow each project's contribution guidelines.
* Do not submit low-quality, copied, or malicious code.
* Never commit passwords, API keys, tokens, or other sensitive information.
* Respect academic integrity.

### 🎓 Academic Integrity

This organization is for **learning and collaboration**, not cheating.

Do not:

* Upload answers to active assignments for others to copy.
* Submit another person's work as your own.
* Ask contributors to complete your coursework.
* Share exam or restricted assessment answers.

Helping someone understand a concept is encouraged. Completing their assignment for them is not.

## 🤝 Contributing

Want to contribute? It's simple:

1. Find a project or issue that interests you.
2. Read the project's `README` and contribution guidelines.
3. Create a branch for your changes.
4. Make and test your contribution.
5. Open a Pull Request.
6. Be open to feedback and code review.

Please keep contributions focused and meaningful.

## 🌱 New to Open Source?

Don't worry.

Look for issues labeled:

`good first issue` · `beginner` · `help wanted`

Everyone starts somewhere.

## 🔐 Security

Never commit:

* Passwords
* API keys
* Access tokens
* Private keys
* Database credentials
* `.env` files containing secrets

Use `.env.example` files where appropriate.
